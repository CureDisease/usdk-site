# usdk.com

Marketing site for USDK: programmable dollar payments for AI agents.

Next.js (App Router), fully static, no database.

```
npm install
npm run dev     # local preview at http://localhost:3000
npm run build
```

Content lives in `lib/site.js` (nav, product and solution pages) and the page files under `app/`.
The contact email is set in `lib/site.js` (`CONTACT_EMAIL`).
